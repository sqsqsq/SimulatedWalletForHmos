## 4. 统计口径

- **统计对象与时间范围：** usage 中有记录即按使用 AI 框架编码的需求计数。标题中的时间为相应需求关联 Git 提交的最早、最晚 committer 时间，不是立项到发布周期；只有一笔提交时起止相同，没有关联提交的不写时间。
- **业务版本：** 初始化时优先取需求明确版本，没有再取工程配置，冲突以需求为准，找不到归未知版本。
- **开发人与代码量：** 通过提交的 `[TicketNo:]` 唯一 AR / DTS 编号关联需求；开发人取 Git author，以邮箱去重，版本间人员可能重叠，全版本人数重新去重。行数是关联提交变更量，不是 AI 生成量；按提交 SHA 去重，merge commit 不重复累计父分支改动。
- **步骤数量与占比：** 使用数按步骤节点存在计，完成数表示该步骤完成过，不表示当前轮或整项需求已完成。各步骤的占比与完成率不相加。
- **初始化环境与平均耗时：** 环境只反映初始化信息。spent 是已结束轮次的日历跨度，含轮内等待与中断，按需求平均，不是 AI 活动工作时间；不同步骤不求总和，组间差异不单独证明模型性能优劣。
