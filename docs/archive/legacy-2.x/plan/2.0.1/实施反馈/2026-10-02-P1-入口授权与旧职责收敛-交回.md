## 3. 实施中的选择（请核）

1. **批处理入口一律拒绝，不限 opencode**。cmd.exe 截断多行 prompt 对所有 npm 包装都成立，内网 codex 若同样装成 `codex.cmd`，也会在启动前报错，要求配原生程序。安装检查关闭时（`check_executable=False`，只造命令）不报。
2. **Case 驱动只认 PATH**。`run_case` 用默认注册，本机要把 `opencode-ai/bin` 排到 npm 包装目录之前。本地注册文件只给直接调用 API 的场景。
3. **submitted 只对系统单成立**，没有 `STORY_REQUIREMENT_SYSTEM_DIR` 时报缺口。比对需求系统上的正文，不比评审记录附件内容：归档后 Review 归人所有，之后机器区可能重投。
4. **交补料只答「已放入。」**。这与 TEST §3.2「只回表示已放入的编号」一致：实跑时宿主按模型当次给的选项回对应编号。
