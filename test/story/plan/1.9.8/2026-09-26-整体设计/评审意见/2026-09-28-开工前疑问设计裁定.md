## 3. 对 §2.2 四份钩子配置的答复

四份 tracked 文件全部迁入 demo 同名位，关联 hook 脚本同时迁入；它们承担消费工程的 Framework 接入，不按“settings”文件名套用个人配置留根规则。根实际个人配置仍保持。

| 文件 | 当前实际内容 | 动作 |
|---|---|---|
| .claude/settings.json | PreToolUse + Stop，CLAUDE_PROJECT_DIR | 配置和 .claude/hooks 随消费工程迁入，环境根指消费工程 |
| .cac/settings.json | PreToolUse + Stop，CODEAGENT3_PROJECT_DIR | 配置和 .cac/hooks 迁入，环境根指消费工程 |
| .cursor/hooks.json | preToolUse，直接调用发布件内 guard | 配置迁入，相对命令以消费工程根为 cwd，发布件不改 |
| .codex/hooks.json | 仅 Stop，旧机器绝对路径 | 配置和 .codex/hooks 迁入；只改 command 为 `node ".codex/hooks/check-phase-completion.mjs"` |

修正实施意见的一处表述：Codex 当前没有 PreToolUse 写保护，且当前 framework codex adapter 未登记生成此 hooks.json。它是历史消费接线，不能算成四个宿主都有当前物化的写守卫。

Codex command 变更单列到 AC03 的迁移必需配置，其他键/脚本保持。消费会话以 demo 或隔离 workspace 为工程根/cwd，清除继承的错误 CLAUDE_PROJECT_DIR；不得替换成新的 E: 绝对路径。验证在 demo 和带空格 workspace 核命令与脚本根解析；未实测的宿主自动触发不宣称成立。
