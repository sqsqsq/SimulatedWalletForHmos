## 3. 语义走查（02 §7 列的七种）

| 情形 | 走查结果 |
|---|---|
| 无 BI 需求 | OBS-07 不命中。只有方案拟新增 BI 时才命中，这时没有依据就不新增，堵住了「材料没写 → 不命中 → 随手加」 |
| 有明确 BI 需求，只带业务维度 | OBS-07 有依据；OBS-05 附注写明 BI 按运营需求带参数、不默认带运维字段，所以合法；OBS-03 只管运维指标，不命中 |
| 有依据借用内外码 | 附注允许，但要写明运营侧的含义与来源 |
| Chart 结果没有外码、也不需要耗时 | 附注写明外码只在确有外部错误码时带、耗时只在指标需要时带；不带是合法的，不会制造空码 |
| 步骤成功 | OBS-03 把步骤成功与全程成功分开列；reporting §3 给出 `STEP_SUCCESS` 与 `SUCCESS` 的对应 |
| 子尝试失败后成功 | 附注写明子点失败不必结束步骤；OBS-03 把重试算作新尝试；reporting §6 的例子对应到校验不通过后重新输入 |
| 复用旧码 / 新语义分配 | OBS-06 未变 |
