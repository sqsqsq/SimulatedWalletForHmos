# S2：通用阶段承接与解耦

依赖 [S1](01-知识规范与Demo样例.md)。本步只修通用内容送达与承接，不把 Chart/钱包协议写入机制。不新增知识类型、表结构、Agent 或判分器。

## 1. 信息如何到达模型

Spec 在适用性判断前读取激活知识原文及必要源码。规约主表是索引，附注/明细中的要求仍有效；不能把文件在磁盘等同于已经送达。Plan 读取上游已选义务及完整来源，确定具体落点；Coding/Review/验证读取对应契约，不重新猜适用性，但可以查实际 API。

| 文件（doc/extensions 相对） | 修改 |
|---|---|
| hooks/spec/author.mjs::knowledgeSection | 从 activeKnowledge 派生规约文件入口，与已有 facts 清单并列；不复制明细、不列固定域名 |
| hooks/spec/author.md | 判断前读取原文；命中要求专项说明的知识时在业务章节独立讲清 |
| skills/story/templates/spec-sections.md、skills/story/phases/spec.md | 专项解释与 §9 技术实体分工；保留现有五张表和短表限制 |
| hooks/plan/author.md、skills/story/templates/plan-sections.md | 承接专项方案到实际实体、数据来源、边界与验证；must 不能只写“遵守规则” |
| skills/story/phases/story-write.md | 在既有功能说明章安排独立可定位小节，用业务语言表达已定专项方案 |
| hooks/coding/author.md、hooks/review/author.md、hooks/ut/author.md | 按实体义务及其明确来源执行；形态与行为证据分开，不新建审查轮次 |
| hooks/shared/pre_verifier.mjs | 保留当前规则与义务装配，增加激活原文入口，避免审查只拿到主表短句 |
| rules/spec-rules.overlay.yaml、plan-rules.overlay.yaml | 在已有语义审查项核专项说明与实体承接；无 Chart 专属 check id |

缺已激活文件响亮失败；空知识仍是合法无专项要求路径。原文指针表达读取时机，不增加已读打卡或重复确认。

## 2. 三份文档各自承载

| 产物 | 位置和内容 |
|---|---|
| Spec | 功能/业务章内独立 H3：节点、结果、数据要求、旧定义影响、验收；§9.4 继续登记精确事件技术实体 |
| Plan | 组件/交互设计内独立 H3：真实调用责任、参数来源、边界和验证；具体义务落 contracts 实体 |
| Story | 功能说明章内独立 H3：采什么、为何、重要边界与变化；技术明细由既有附录/引用定位 |

标题随业务命名，不固定叫 Chart。没有适用要求不建空章；保留十章职责。详细码值/字段如果业务确实需要，须在 Spec 技术明细或可定位的真实定义中取得，不能移动叙事后让附录丢技术行。

must 挂到真实决定节点结果的业务方法，字段要求挂实际数据实体；不能全压到 SDK Builder。义务包含具体可观察行为或引用同一契约内明确实体定义。验证方式沿模型/构建/实机等现有协议；实机选 ut/device/both。Demo 只到 Plan 不意味着把真实需求的运行验证改成 Review。

## 3. 过拟合与交接检查

通用生产代码、提示、默认值和断言均不得依赖钱包名称、编码位数、四类结果、样例节点数或字段集合。实际生成内容可以引用当前知识里的这些值，审查其来源。Demo 运行代码不导入 Extension、不读取知识 Markdown 决定业务。

S1 的旧规则在原责任位置退出，原探针引擎保留；方法出现只作取证线索，不负责双报或场景覆盖。历史报告不追溯改写。adaptation 继续保护目标知识，首次骨架与部件画像行为不变，不自动灌入 Demo 规范。

## 4. 验证与交回

在现有 author_task_package、knowledge_protocol、knowledge_use、neutral_knowledge、empty_knowledge_repo、spec_contract_section、writing_plan、story_build 相关测试补有区分力的用例，按 TEST 并行执行。

中性知识不仅换名，还改变编码格式、结果集合、可选字段和 API 形态；至少包含合法的不带取消、不带耗时的节点。检查清单派生、实际来源、契约引用及作者/verifier 输入；不以固定标题或复制知识全文作金样。

保留 §9 五表、非表文字约束与附录投影回归；换合法小节标题仍可成立，无专项要求不强制补章。结构测试不宣称模型理解，实际成品由 S4 评价。交回源码→任务输入→实体义务→审查来源对照、旧内容退出与预算实账。
