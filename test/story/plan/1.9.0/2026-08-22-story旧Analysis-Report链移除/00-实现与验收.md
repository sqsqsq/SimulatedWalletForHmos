# Story 旧 Analysis/Report 链移除：实现与验收

## 目标

Story 测试域只负责自动启动、观察、交互驱动、恢复、原始事实保存和回灌，不再维护独立的内容评分链。

## 删除范围

- 删除旧取材、断言和独立审阅合并脚本及其专属测试。
- 删除整套判据目录和 Case 评价目标字段。
- runner 不再产生或读取额外报告数据、评分字段与兼容参数。
- 当前 TEST、AGENTS 和 Case 只描述最新自动观测流程。

## 当前输出契约

- 单 run：`state.json`、`events.jsonl`、`live.jsonl`、`runlog.md`、worker/gate 日志、phase results、artifact。
- 单 Case：不可变 `observations.jsonl` 与汇总 `observation-record.md`。
- suite：执行、稳定观测、交互、错误、回灌及 workspace/output 延迟清理事实。
- 退出码只表示正常完成并到达目标阶段，或 CLI、gate、恢复和基础设施错误。

## 验收

- 删除资产不存在，当前入口和脚本不再引用旧字段、旧参数或旧输出名。
- 单 Case 与多 Case 状态只依赖 state/events；成功和失败终态均可回灌。
- workspace/output 延迟清理与连续两轮 Spec 稳定切换测试继续通过。
- Story 单测、Tools CLI 单测、Python 编译、CLI 校验和只读多 Case plan 通过。
- 验收不启动真实被测 CLI，不清理现有现场，不迁移 `doc/features`。

## 迁移位置修正

主工程现有 `doc/features/*` 在新 suite 起跑时整批迁移到
`E:\Project\bak\Story-Features-<时间戳>/`。suite output 仅保存 `feature-migration.json`，不再包含
feature 文件副本；该归档不随下一轮 suite 清理而删除。
