## 方案 B18 的论证有个漏洞，一条用例当场证明了

方案写：「已核：`reached()` 只被 `:302` 与 `:373` 用 `'complete'` / `'story_written'` 调用，删第三项不改变任何现有行为。」

**它核的是调用点传进去的 `atLeast`，没核契约里 `status` 可能是什么。** 删掉之后 `test_archived_passes` 当场红：那条用例写一份 `status: "archived"` 的契约，要求判据放行。

我按「这条断言守的是什么」判了一遍：

- 契约的**唯一写入者**是 `story_flow.py`，它的 `cmd_archived` 写的是 `contract["archived"]` 字段，`status` 仍是 `story_written`——所以 `status: "archived"` 是一个**从不产生的值**；
- 那条用例守的不变量是「判据问的是到没到某个点，答案是区间不是值」（`FLOW_STATES` 上面那段注释记着教训：写成等于某个值，成文登记后四个已闭环的阶段会集体翻红）；
- **这个不变量拿真实状态就能守**：`status_written` 比 `complete` 靠后，`test_registered_passes` 放行就是区间语义成立。哪一条判据写成 `status === …`，它立刻红。

所以：删第三项，退掉那条拿虚构状态做输入的用例，把不变量写进 `test_registered_passes` 的注释里（说明它同时守什么、以及退掉的那条为什么不再需要）。**行数上这是减一条用例，行为上一条防线都没少。**

## 我在这一部分犯的一个错

收敛 `spec/post_check.mjs` 的 `featuresDir` 时，我在一段批量替换里**漏给一条 import 替换加 assert**——那个文件本来就没 import 过 `paths.mjs`，替换静默无操作，于是文件里出现了一个**没有 import 的 `featureRoot`**。

更糟的是我随后拿 `node -e "await import(...)"` 做冒烟，它打印「模块可加载」——**ESM 的未定义标识符只在执行到那一行时才报错**，import 阶段一句话都不说。假绿。

是我下一步 grep import 行时自己发现的，随即补上 import 并解决了变量遮蔽（局部变量与导入函数同名，改用 `featureRoot as featureRootOf`）。

两条教训，都写成动作：

1. **批量替换里每一条都要 assert 命中**，不能只给其中几条加；
2. **「模块能 import」不是「引用都解析得了」**——冒烟要跑到真的执行那条路径的用例，否则就直接跑全量。
