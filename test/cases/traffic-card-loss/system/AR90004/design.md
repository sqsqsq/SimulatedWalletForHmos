# AR90004 交通卡紧急挂失（钱包端）

> 本单由系统设计拆分下发，正文先由上游填了一版，开发接手后按各自模板补全。

## 上游先写下的几条

- 页面在一页里承载资格查询、风险确认、身份回跳、状态冲突、提交与结果，不拆多页；
- 冻结与否以云侧返回为准，端侧任何分支都不得自行认定成功；
- 同一张卡存在处理中的申请时复用它，响应丢失后重试也不能创建第二份；
- 中断后回来要能接着上次的位置继续，账号变了就清空重来；
- 云侧确认冻结后把 `freezeTicketId` 和最终状态交给补卡那张单。
