## N1 评测通路打通（已实施）

`opencode run [message..]` 的 positional 是 **yargs array**，多行 prompt 把后续选项一并吸走
——`--format json` **从未生效**。由此三个症状同源：`model` 流全空、`session_id` 拿不到、
无法 `resume` 因而驱动器答不了 S3 关卡菜单，单轮会话就此结束。

**三跑三种授权措辞全部失败**，一度被误判为 skill 缺陷（详见 01 的定界与两次错误修法记录）。

修复：`clis.json` 把 `{prompt}` 移到所有选项之后（4 个 profile）；`run_case.py` 加续话循环
（判据只看**产物是否齐备**，不看菜单文本）；`tools/cli/tests` 加断言钉住参数顺序（**只约束
opencode**——这条是从它的 yargs 实证来的）。

结果：AR90004 跑通，2 轮 / 39 分钟，三门禁全 pass，`mechanical_verdict=pass`。
