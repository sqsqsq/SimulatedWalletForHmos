## 11. HarmonyOS API 断言汇总（模型新增，按核实来源分组）

**A. 官方文档直证**（华为开发者文档站，context7 检索原文）：

- [ ] `exported: false` 禁止外部拉起；绕过需仅系统应用可用的 `ohos.permission.START_INVISIBLE_ABILITY`（SEC-03）
- [ ] `want.parameters` 默认携带 `ohos.aafwk.param.callerPid` / `callerUid` / `callerToken`（SEC-03）
- [ ] `UIAbility.onSaveState(reason, wantParam)` 存在，与 appRecovery 配合（ENV-02）
- [ ] 恢复路径 = `onCreate` 判 `launchParam.launchReason === AbilityConstant.LaunchReason.APP_RECOVERY` + `restoreWindowStage`（ENV-02）
- [ ] 开关 = `context.setRestoreEnabled(true)` 或 `appRecovery.enableAppRecovery`（ENV-02）
- [ ] `onMemoryLevel(AbilityConstant.MemoryLevel)`：AbilityStage 与 UIAbility 均有，同步，MODERATE/LOW/CRITICAL 三级（ENV-05）
- [ ] `systemDateTime.getUptime(TimeType.STARTUP)`：单调、含深睡；`getRealTime`/`getRealActiveTime` 自 API 12 废弃（ENV-04）
- [ ] 长时任务：`backgroundTaskManager.startBackgroundRunning` + `module.json5` abilities 的 `backgroundModes` + `ohos.permission.KEEP_BACKGROUND_RUNNING`（DFX-03）
- [ ] 延迟任务：`workScheduler` + `WorkSchedulerExtensionAbility`；短时任务有配额（单日约 10 分钟）（DFX-03）
- [ ] `canIUse('SystemCapability.*')` 做运行时能力判定；`@since` 仅文档标签、无运行时效力（COMPAT-12）
- [ ] `compatibleSdkVersion` 属工程级 build-profile.json5；`minAPIVersion`/`targetAPIVersion` 在 app.json5 中由构建生成、手改无效；`deviceTypes` 属 module.json5（COMPAT-12）
- [ ] 打包一致性：`minCompatibleVersionCode`/`targetAPIVersion`/`minAPIVersion`/`debug` 须各包一致，HAP ≥ 其含的 HSP（COMPAT-12）
