# AR90006 交通卡自动充值（钱包端）

> 本单由系统设计下发，正文先由上游填了一版，开发接手后按各自模板补全。

## 上游先写下的几条

- 判定与扣款全部在服务端，端侧只承担签约入口、签约交互与状态展示，不存在「发起自动充值」的动作；
- 判定输入是服务端记录的余额，不是手机上显示的余额——离线刷卡后端侧余额长时间不准；
- 免密扣款的单笔上限随用户选择的面额设置，不是固定值；
- 同一张卡已有生效签约时复用既有合约，不重复建立；
- 功能开关只管新签约入口，已签约用户的自动充值照常发生；
- 连续 3 次扣款失败由云侧停用签约，用户要能看到原因并重新签约。
