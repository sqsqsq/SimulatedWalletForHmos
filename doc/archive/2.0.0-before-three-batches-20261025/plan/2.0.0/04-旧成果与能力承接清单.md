## 七组发布遗留落到现有责任

1. 未决与材料：蓝图作者在取材前读有效人签/范围，candidate中保未定；Story作者及独审核同一决定贯穿正文、图、契约和AC。B原有规则已经涉及未知/失败，迁移时保证实际送达和应用，不把原案例词句再加成硬编码判据。
2. 旅程/设计：component-design设计完整性与Story业务组织共同负责，核入口前提、数据生产/身份/使用/反馈、模式角色与适用资源义务；CU Plan落实具体entry_symbol与实体落点。外部缺口显式保留，不造API。
3. 独审：14解决真实输入/派发/回收，02解决先首读后核源；是否发现上述缺口以F证据判，不默认增加角色/轮次。
4. usage：D将begin放到实际作者入口并核全链调用，F对照首个业务读取与开始事件；记录器正确和模型准时执行分别验。
5. 交互/表达/成本：沿B既有授权推进、图后条件和来源说明，完整首稿与必要返修；measure_run区分等待/执行/协议成本。不设任意30分钟产品门槛。
6. SVG：保持已实现通道、观察选择理由与阅读收益，零SVG不作通道失败。离线可构造合法增强例验证切换/绑定，不向业务作者强塞图形数量要求。
7. 测试统计：12在measure_run/observe/run_case修计数范围和截断披露；保留原生事件取证。它属于装置，不给Extension增加产品gate。

以上是处理责任，不是七项已关闭；闭合需要对应新组合证据。尚未取得的行为和效果在交回中列未验证，残余接受由用户裁定。
