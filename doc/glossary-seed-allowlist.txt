# ============================================================================
# 种子技术词豁免清单 (doc/glossary-seed-allowlist.txt)
# ============================================================================
# 作用：Skill 0 Phase B 对 doc/glossary-seed.txt 做"技术词守门"时的豁免名单。
#      默认会把下列行视为技术词而 BLOCKER 拦下：
#        a) 纯英文驼峰（^[A-Z][a-zA-Z0-9]+$），如 AccountManager / HomeTabPage
#        b) 等于 doc/module-catalog.yaml 里某 module.name
#      把这类词写入本文件则放行。
#
# 格式：
#   - 纯文本，每行一个术语
#   - # 开头的行 = 注释，忽略
#   - 空行忽略
#
# 使用边界：
#   - 本文件**只给极少数行业通用英文缩写**用（HAP / SDK / NFC / ArkUI / ArkTS 等）
#   - **不要**把 catalog 里的技术模块名（AccountManager / CardManager 等）加进来——
#     那是业务映射错位，正确做法是把种子改成中文业务词
#   - 每加一行都建议加 `# reason: xxx` 尾注说明为什么这个英文词在本工程里算业务口径
#
# 示例（**默认全部注释掉**，按需启用）：
# ----------------------------------------------------------------------------

# HAP          # reason: 行业通用缩写，PRD 与业务团队会直接说 "这是 HAP 入口"
# SDK          # reason: 行业通用缩写，暂在 sandbox 不启用
# NFC          # reason: PM 常直接用英文缩写指代 NFC 相关流程
# ArkUI        # reason: 平台名，业务团队也会直接用
# ArkTS        # reason: 平台名
