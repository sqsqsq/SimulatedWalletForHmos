# 部件画像

**本部件是谁、承担什么、与谁交互。**

## 1. 部件申明

- **部件名称**：单框架钱包 / 纯鸿蒙钱包 / 钱包客户端 / WalletForHMOS
  （上游文档中出现上述任一称谓，均指本部件）
- **部件职责**：承载手机侧华为钱包应用的功能与需求；**包含**通过蓝牙连接穿戴设备后
  对其卡片进行远程管理的穿戴卡包功能；**穿戴设备上独立运行的钱包应用不属于本部件**
- **运行形态**：手机应用（**纯鸿蒙 app，自行发布，非 SDK 提供方**）

职责范围具体化：卡证票券（银行卡、交通卡、门钥匙、证件、票券）在手机上的添加、展示、
使用与生命周期管理。凡与之无关的上游内容，不属于本部件需求。

## 2. 交互方清单

判定「某段上游内容是否与本部件相关」时，按以下六类交互方逐一核对：

| # | 交互方 | 交互方式 | 说明 |
|---|---|---|---|
| 1 | 服务器接口 | HTTP/RPC 请求 | 本部件对钱包云侧服务发起的调用（接口、时序、错误码） |
| 2 | 元服务 | 卡片/轻量化形态 | 元服务卡片承载的入口与展示 |
| 3 | H5 | web 容器 | H5 页面承载的业务流程（活动页、协议页等） |
| 4 | 手机系统接口 | 系统 API/权限 | 系统能力依赖：权限、卡片框架、NFC 控制器、蓝牙等（刷卡、门禁、车钥匙等近场交互经此类能力实现） |
| 5 | 其他手机应用 | 拉起/被拉起 | 收银台、银行 app、deeplink/want |
| 6 | 穿戴设备 | 蓝牙远程管理 | 手机侧对穿戴设备卡片的远程管理（穿戴侧独立运行的钱包 app 不属本部件，见 §1） |

命中任一交互方 → 与本部件相关；均不命中（如纯云侧内部改造、其他部件独立排期项）→ 不相关。
