# 工程惯例与取证导航

**这个工程有哪些能力、各自在哪、怎么用。** 取证公式「事实 = 变更意图 × **代码库现状**」的
现状那一半，第一落点就是本文件。

## 总则

任何一类能力——打日志、上报、脱敏、存数据、读配置、跳页面、写界面——这个仓里大概率已经有做法。
**先找到它，照它写**：不绕过封装直接引平台 API，不另起一套。
既有实现与本需求确实不匹配时，先说明哪里不匹配再新增。

## 这个工程有什么

### 可观测性

日志、VOC、Chart 三条渠道齐备，都在公共能力模块：日志在 `shared/log/`，两类上报在 `shared/ha/`。

`shared/ha/` 提供统一门面，分 info / error / debug 三档，每档同时记日志与发 VOC；
单独发 Chart 用对应的 Builder。上报字段由基类的链式 setter 提供，是受控集合，不随手加。
业务终态取受控枚举（成功 / 步骤成功 / 用户中止 / 异常失败），不自造字符串。
上报非阻塞，失败只记本地日志。

### 敏感数据处理

通用脱敏工具在公共能力模块的 `shared/utils/`；业务专属脱敏（按业务规则留头尾这类）
在对应业务模块的 `shared/utils/`，不上提公共层。

### 数据存储

关系型持久化封装在业务模块 data 层的 `*RdbHelper` 形态里，持有单例 Store、配置带安全等级；
内存态用平台的应用级存储，出现在 domain / service 层。
**已核实未使用**：平台的轻量偏好存储、分布式键值存储。

### 配置项

常量开关在各模块存放常量的目录下，形态是 `static readonly <NAME>: boolean`；
同目录另有非布尔的业务常量类，按类型区分。
**无远程配置封装**（已核实）：没有管理台或云侧下发开关。

### 对外暴露面

三处认：应用清单里 ability 的对外可达声明、页面路由注册表、跨模块跳转的统一入口
（导航栈由公共能力模块持有）。

### 端云接口

**无端云封装**（已核实）：数据来自本地仓储层。

## 找不到的时候

用模块画像与模块目录缩范围，再在范围内检索。画像只登记关键导出，
**「画像里没有」不构成「工程里没有」**——「无」只能由检索零命中得出。

写「无」时给出核对依据：查了什么、在哪查的、零命中。
