# DFX 基线（性能/功耗/ROM/RAM）

管性能量化基线与功耗/包体/内存的引入评估。性能指标本体写在 spec「非功能性需求」章节，本文件提供基线值与高风险场景清单。

> 「出处」列指向上游 story 模板规约（HarmonyOS）的章节号；标「工程增补」者规约中无对应原文。「等级」与「判定方法」两列规约未定义，整列均为工程增补。

## 基线值

规约 §13.1 要求评估「启动时延、加载时延、滑动丢帧、启动丢帧」，但**未给出任何数值基线**。下表的指标项取自规约，具体数值待内网性能基线录入——**在此之前不得臆造数值，spec 非功能章节的量化指标须由需求自身论证，不得引用本表**。

| 指标 | 基线 | 出处 |
|---|---|---|
| 冷启动时延 | <待补充：以内网性能基线为准> | §13.1 |
| 加载时延（首屏可交互） | <待补充：以内网性能基线为准> | §13.1 |
| 滑动丢帧率 | <待补充：以内网性能基线为准> | §13.1 |
| 启动丢帧 | <待补充：以内网性能基线为准> | §13.1 |

## 条目

| ID | 条目 | 出处 | 等级 | 判定方法 | 例外条件 |
|---|---|---|---|---|---|
| DFX-01 | 性能：新页面/新流程有量化指标（spec §非功能），且不劣于基线 | §13.1 | 红线 | spec 非功能章节含数值 + 对照上表（基线待补充时只校验「有数值且有论证」） | — |
| DFX-02 | 功耗-高频场景：IO 读写/IPC/网络接口/文件读写/数据库访问/三方 SDK 调用有频次评估，无必要高频调用；通过合理的缓存设计降低接口访问频次 | §13.2 | 基线 | spec 流程图数调用次数 + spec §9.1 端云接口的触发时机；端云接口另按 §7.1.1.3「请求量和 QPS 风险评估」排查定时任务/开机启动任务/定时是否离散、是否并发、有无缓存方案、请求间隔是否合理 | 无上述调用 |
| DFX-03 | 功耗-常驻进程：后台禁止不必要的业务逻辑 | §13.2 | 红线 | 代码落点是否含后台/常驻任务 | 无后台逻辑 |
| DFX-04 | ROM：新增预置图片资源/新增 SDK 依赖（含 so）/SDK 升级/新增 hap 包的体积引入已量化 | §13.3 | 基线 | spec §9.5 依赖变更的体积影响列 + 资源目录 diff | 无新增资源/依赖 |
| DFX-05 | RAM：常驻内存与后台峰值内存影响已评估（尤其常驻进程改动） | §13.4 | 基线 | <待补充：内存基线与测量方法> | 无常驻改动 |
