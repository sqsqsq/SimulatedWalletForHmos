# 资源使用

管图片与字符串的来源选择：先复用，再新增。

## 条目

| 编号 | 约束 | 强制力 | 命中条件 | 处置 | 验证（执行体） | 探针 |
|---|---|---|---|---|---|---|
| RES-01 | 图片按优先级取：系统图标 → 项目已归档图片 → 新引入；新引入的单张不超过 10KB | 基线 | 需求含界面图片或图标 | 逐张说明取自哪一级；新引入的给出实际体积与前两级不满足的依据 | 模型：核对资源目录 diff，逐个新增图片有无体积与选型说明 | 无 |
| RES-02 | 字符串优先复用项目已有、中文完全一致的资源；确需新增的按项目惯例定义并引用，中英文齐备 | 基线 | 需求含用户可见文案 | 逐条说明复用了哪个已有资源，或新增的定义位置与引用方式 | 模型：检索既有资源中有无中文完全一致的条目；核对代码里有无用户可见的中文字面量 | 无 |

## 判定附注

- **10KB 是本工程设定值**（非平台限制）。
- **「完全一致」按中文原文判**：同样的字用在两处就是同一个字符串；意思相近但字面不同的另建条目。
- **依赖方向挡住复用时可临时硬编码**，同时在交付结果写明：哪个字符串、硬编码在哪、建议下沉到哪一层。
- RES-02 新增字符串时同时命中资料交付域的翻译条目。
- 图片放哪、字符串在哪定义、系统图标怎么引用：按项目知识找同类的既有资源。
