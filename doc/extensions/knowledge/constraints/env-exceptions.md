# 环境异常标准场景库

管「用户调整设备环境」导致的异常场景——spec 异常场景表的门禁基础三类（网络/空数据/权限）之外最易遗漏的一族。

## 异常三分类（§3.3 原文框架）

规约 §3.3 要求异常分析覆盖三类，**本文件只承载第三类**；前两类由 spec 异常场景表按同一框架分类：

| 分类 | 定义 | 承载处 |
|---|---|---|
| 预期异常 | 设计方案上就有兼容的异常场景，如 AT 失效、订单过期 | spec 异常场景表（注：特殊分支不属于异常场景，如非身份证开户，应在实现方案中说明分支处理细节） |
| 非预期异常 | 无针对性兼容设计，采用通用兜底逻辑，如接口报错、无数据返回 | spec 异常场景表 |
| 环境异常 | 用户调整设备环境可能导致的异常 | **本文件下表** |

## 条目

| ID | 场景 | 出处 | 典型表现 | 兜底要求 |
|---|---|---|---|---|
| ENV-01 | 清除缓存/清除数据 | §3.3 | 本地状态丢失、首次引导重现、凭证失效 | 功能可自恢复或引导重建，不崩溃不死循环 |
| ENV-02 | 中途杀死应用 | §3.3 | 流程中断（如支付/开卡进行中被杀） | 重进后状态可恢复或明确回滚，无中间态残留 |
| ENV-03 | 重复拉起 | §3.3 | 多入口快速重复进入、深链重复触发 | 防重入（幂等/防抖），无重复下单/重复弹窗 |
| ENV-04 | 调整系统时间 | §3.3 | 时间回拨/快进影响有效期、缓存过期、签名时间戳 | 有效期/时序逻辑以服务端时间或单调时钟为准 |
| ENV-05 | 进程后台被回收 | 工程增补（§3.3 列举四类后有「等」字，本条属其外延，待与内网核对） | 长时间后台后返回，页面栈/数据被系统回收 | 状态恢复策略已声明 |

## 回显指引

应用域约束符合性表的「环境异常」行：判定新功能是否引入受上述场景影响的状态/流程；「是」→ 对命中 ID 声明兜底策略并确认已列入 spec 异常场景表（证据 `env-exceptions:ENV-xx` + spec §异常）；「否」→ 说明为何无状态可受影响（如纯静态展示）。
