# 应用特殊配置

管钱包 app 级生命周期与卡片类数据的特殊配置项；每个需求须回答「是否触碰这些系统级行为」。

> 「出处」列指向上游 story 模板规约（HarmonyOS）的章节号；标「工程增补」者规约中无对应原文，须与内网核对后确认或删除。「等级」与「判定方法」两列规约未定义，整列均为工程增补。

## 配置项必要性评估（§9.1.1）

新增管理台配置项前须先评估必要性，不是「能配就配」：

1. 精细化的配置管理虽然在特性上下线的管控上更灵活，但会带来更高的**配置维护成本与风险**；
2. 依赖外部合作伙伴或系统组件的业务特性，**建议以外部配置或能力协商接口为准**，不在本部件另起配置项。

评估结论与配置内容、使用说明、版本兼容性一并写入 spec §9.3 配置项（规约 §9.1.2–§9.1.4）。

## 回显指引

应用域约束符合性表的「应用特殊配置」行：无卡片/凭证/启动期改动 → 「否 + 现状证据」；否则逐命中 ID 声明，编号写「应用特殊配置规约 APP-xx」。APP-01 的具体配置项本体写在 spec §9.3 配置项，此处只回显管控结论。
