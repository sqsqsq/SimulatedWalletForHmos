## 三、第一波（摘要）

**痛点**：Scope creep（design 擅自扩模块）；弱模型 ArkTS 错误率高。  
**手段**：PRD / design / coding 三阶段 Scope BLOCKER；`scope-parser` 共享；`diff_within_scope`；`arkts-pitfalls.md` + 逐文件 ReadLints；`CLAUDE.md`、trace、`gap-notes`。

**试金石**：`bank-card` 越界 design → `scope_consistency_with_prd` FAIL。  
**局限**：`check-design` 接口签名启发式误报；`diff_within_scope` 基线需 `HARNESS_DIFF_BASE_REF` 等。

→ **完整 WP 清单、dry-run 数字、试金石步骤**见 [第一波改造-沙盒自检报告.md](./第一波改造-沙盒自检报告.md)。

## 四、第二 + 第三波（摘要）

**痛点**：Scope 对了，PRD 仍可能「自然语言 → 错误模块」（如卡中心 vs 卡管理）。  
**手段**：

- SSOT：`doc/module-catalog.yaml`、`doc/glossary.yaml`
- **Skill 0**：`/catalog-bootstrap`、`/glossary-bootstrap`；`harness --phase catalog|glossary`（无 `--feature`）
- 护栏 **A–D**：glossary 反扫 `NOT_responsible_for`、catalog `typical_vs_not_responsible_conflict`、alias-merge、module-card 反向自检
- **P0-1～P0-4**：反向指针、种子技术词 + allowlist、`easily_confused_with` 对称、自引用/空 module BLOCKER

**沙盒实证**：删 catalog/glossary 后从零自举；「账户」四护栏联动后并入「账号」alias。  
**局限**：P0-3 豁免为文本关键字、种子 allowlist 全局、Step 2.5 中文正则等。

→ **Phase A/B 逐步流水、负向构造表、改动文件列表**见 [第二三波改造-沙盒自检报告.md](./第二三波改造-沙盒自检报告.md)。

## 五、U1 / U2 / C1 / C3（第四批增量摘要）

以下在第二三波报告定稿之后合入主干（具体以 `git log` 为准）。

### 5.1 U1 — Skill 0 单命令 UPDATE

- **入口**：仍只用 `/catalog-bootstrap <M>`，内部判别 CREATE / UPDATE。
- **行为**：UPDATE 时 Step 5.1 用**字段级 diff**（旧→新、+/-、unchanged 折叠），避免整表重贴；`q` 表示丢弃本次刷新、保留旧画像。

### 5.2 U2 — `key_exports_fresh_vs_index`

- **规则**：HAR 模块比较 `catalog.key_exports` 与 `entry_file`（Index.ets）顶层 export。
- **WARN**：catalog 有而代码无（强信号）；或代码有而 catalog 无且未达条数上限（漏记）。

### 5.3 C1 — PRD 术语与 Scope / 正文

| Check ID | 级别 | 含义 |
|----------|------|------|
| `terminology_modules_within_scope` | BLOCKER | 术语映射表「权威模块」 ⊆ `in_scope_modules` ∪ `out_of_scope_modules` |
| `glossary_terms_used_in_body` | MAJOR/WARN | glossary 术语（含 aliases）在 PRD 正文出现但未进映射表 |

**沙盒示例**：`home-page` PRD 补「设置 → WalletMain」一行后，C1b 由 WARN 归零。

### 5.4 C3 — catalog 对 feature 的反向扫描

| Check ID | 级别 | 含义 |
|----------|------|------|
| `feature_scope_integrity` | MAJOR/WARN | `doc/features/*/PRD.md` 与 `design.md` 中 Scope 引用的模块须在**当前** catalog 建档 |

**沙盒现状**：`bank-card/PRD.md` 引用尚未沙盒建档的 `BankCard` / `CardManager`；`home-page/design.md` 仍含历史 `out_of_scope_modules` 长清单 → catalog 阶段 **预期 WARN**（真实漂移，非误报）。清 WARN 路径：补档、或收敛 design 与 PRD / 真实 catalog。
