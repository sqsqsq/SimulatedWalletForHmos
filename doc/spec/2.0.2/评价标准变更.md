## 4. 验证与样本接续

继续自动充值和车钥匙两组既有业务，不加第三个独立需求。正常业务送审与实际CU到Plan的既定能力目标保持；update及受影响恢复也保持原要求，具体本版里程碑、输入/人答、终点及运行许可由后续Plan固定。2.1明确不测的阶段仍是历史未覆盖，不倒填失败、不要求旧suite补跑。

L1验证局部确定性规则；L2核真实生产→消费及身份/恢复；L3核安装物化与独立可重建组合；L4核模型真实送达/理解/应用/交付。输入不得预填被测生产结果，不能把人工修稿、移文件、改报告或维护答案注入算正常链。E批现有分析可用于本版Plan，但不自动获实施授权。

Coding/设备/真实内网/视觉、完整安装适配和usage/stats未取得的证据单列；不把环境缺失写不适用，不强索未来阶段证据阻全部文档设计。条件稿可成立，具体外部依赖限制对应完成结论；内部错误不能因此豁免。
