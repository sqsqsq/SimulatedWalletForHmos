## 4. 判据生效及结果边界

新增/变更的正常与负路径由Plan绑定真实生产消费接缝，标准不直接规定函数/目录数量。必须涵盖：自由或部分答复、第三方未决、零CU共同验收、合法Spec复用、当前/过期反馈、纯收尾与实质变化、真实回复/失败/补正、冻结后合法来源修订、归档集合变化及保持项。

至少一例明确update是本版测试条件；具体Case与宿主、金样逐份晋升、有效标准新修订及真实运行需按既有授权流程固定。2.0.4 car既有边界后的诊断支持机制需求，但正式评分仍暂停；本页不豁免TEST或回写旧分。身份检查、独立语义及真实效果分别结论，三轴各≥90且经用户确认才算目标达成。
