### 8.7 度量方法学结论（CLI 对照与 S4 的自我约束，逐条）

1. 状态分离：进程结束、门禁、业务正确、阅读完成、发布就绪分别判断（CLI对照:29）。
2. 证据不回写：「不将后续实现或离线通过追写成该次运行的收益」（CLI对照:13）；「反例修正后重验受影响路径，不修改既有 run 原件补通过」（04:172）。
3. 一次运行不支持成功率（CLI对照:304）；「完成样本的时长分布只是完成成本，不能当总体成功率」（04:130）。
4. 历史对比三层级与规则（04:124-136；§6 储备表已录）。
5. 归因规则：源文件被读取的原因归入未送达/合同矛盾/内部工具调查/主动丢弃信息；「不能限次数/禁读源码/删审查来制造性能收益」（CLI对照:327）。
6. 措施 ≠ 收益：「下表列的是设计措施，不是已验证收益」（CLI对照:41）。
7. 维护规则：新运行单独注明 suite/对象/日期，不能覆盖旧运行事实；「未知保持未知，用户评分另记实际裁定」（CLI对照:447）。
