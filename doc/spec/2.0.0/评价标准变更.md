## 8. 2026-10-26完整承接纠偏的映射

本节细化既有能力保持与维护交付结果，不增加第二套评分体系。此前“来源表链接已统一改到1.x归档”仅记录当时实施，不能作为继续撤下1.x正常历史的要求；恢复正常历史后，由Plan同步活跃引用，固定来源快照及原报告身份仍保留。

| Spec结果 | 适用依据 | 正常/反例与当前结论边界 |
|---|---|---|
| §2.4正常版本主线与旧2.x归档 | 本版Spec的维护资料验收、项目历史保留约定；不强塞为新增产品评分条目 | 能从正常1.x→1.9.9→新2.0.0找到成套版本资料；旧2.x留旧轮次archive。把1.x仅留跨分支差异集、把旧新同号2.x混为正常主线不满足。尚未实施本次目录纠正 |
| §2.5历史运行数据 | 本版用户决定及G4证据身份边界 | 发布前位置、版本和可取得状态明确且数据不动；Git外文件不能只给Git SHA充作取得方式；发布后统一本地迁移是后置工作，不作为现在必须搬完的条件 |
| §2.6完整材料独审 | A3/A4/A6、G1/G3及本版Spec | 对未采用但需要核源的冲突阅读稿、图和纠偏留痕，漏必审应被发现；真实有效来源的发现可消费。任务与覆盖/发现定位集合必须一致；额外取证不替代缺失必审。现已查实承接缺口，未修复，不因@19或R1–R4局部通过而关闭 |
| §2.6 CU文档自洽 | 来源P的引用真实性要求、G3可计算事实职责及本版Spec | 带号引用与真实章、父子编号一致；合法自由分节与新模板无号章可成立。原生与扩展的具体承担由Plan核清，不直接恢复旧固定章号/位置约束；实现与替代验证尚待落实 |
