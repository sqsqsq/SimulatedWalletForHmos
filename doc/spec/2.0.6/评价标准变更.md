# 2.0.6 整版评价标准变更

2026-11-23，随[正式 Spec 修订 1](2026-11-23-目录调整与适配.md)定义本版的目标判法。基准为 2.0.5 冻结的 [extension-acceptance@33](../../../test/regression/extension-acceptance.md)，58 项，SHA-256 `0dc2e48e8c92dd6420b2d08442cd4e8274f562ea108b3ea552796dbfc4b13ea0`。本页只写相对基准的变化；下表与 @33 共同用于 2.0.6 方案和验收准备。历史运行仍按原对象和当时标准保存。正式候选采用时在全量标准正本落定条目修订及文件身份，当前不预签一个尚未冻结的标准版本。

| 基准条目（58 项全覆盖） | 本版补充或替换的判法 | 验收 |
|---|---|---|
| A1–A8 取材与澄清 | 沿用来源、采用、图片效力、会议和责任判法。确认记录必须指向当轮实际材料，不接受手工复制前轮通过态。 | AC04、05、11 |
| B1–B8 人读交付 | B2/B4/B5 核责任、范围排除、中间态与精确查阅；B6 核正文、图、异常及验收是否一起更新；B8 收窄独审为最终稿写作与忠实度，普遍评价原始材料到蓝图的取舍回设计问询。B7 沿用 AR 成文及非 AR 授权规则。 | AC04、06–08、10 |
| C1–C5 人工决定 | 沿用来源和权限；新答复真正生效后追踪到发布当前稿、验收及受影响阶段。缺权和临时授权能分辨，业务读者不会同时读到已定和旧待定。 | AC05、07、11、12 |
| D1–D10 知识链 | D1/D3/D6/D10 按当次决定与实际承担者判。允许同因排除合写并保持可追；示例不得成为项目既有编号、规则或接口。D5 核同一义务在实体、方法、共同验收是否相容；合法不同表达要从实际门禁与独审两端对照。D7、D8 按真实达成阶段取证。 | AC09–11 |
| E1–E6 变化与恢复 | 保三方合稿、真实材料版本、受影响部分更新、撤回保护。核本轮报告、修订、登记与交付身份；仅有新稿文件不能证明已收口。 | AC07、11、12 |
| F1–F4 交付 | 原业务送审、系统发布、部分失败、外部冲突与恢复保持。按当轮身份和实际授权判，未写稿的路径不虚构收件或既有稿更新。 | AC04、11、13 |
| G1–G5 协作与评价 | 首次决定前送达、缺口定位与原生接续保持。G3 对可信完成来源、当前材料和报告原件核实；G4/G5 统计不同对象与实际报告，校验测试边界、等待与干预。受污染段停止正式评价，事后成稿诊断注明限制。 | AC07、08、11、14、15 |
| H1–H4 安装与升级 | 以外网包、内网导入、业务首装及既有工程升级分别判。根 manifest、base 唯一源、宿主入口、样例清理、真实 adapters、项目自有知识、游标与重复执行均核实际落点。只渲染说明或仅直调脚本不能签宿主可用。 | AC01–03、15 |
| I1–I8 产品使用记录 | 需求起点/完成、版本、Git 归属、统计、降级和正常收尾均保持。测试套件观测与产品 usage 各用本职责的证据。 | AC14、15 |

## 初段基线发现的去向

| 2.0.5 独立复评发现 | 2.0.6 规格与判别样本 |
|---|---|
| R1、R2 来源、稿件遗漏与阅读负担 | R04–R06。原责任和中间态在蓝图成立，读者可在 Story 找到完整业务路径。 |
| R3、R4 人答未同步、终稿失效与未完成 Plan | R04、R06、R09、R10。核最新真实人答、蓝图、成品、当前报告与原生范围；区分错误产物与未执行检查。 |
| R5、R6 知识相互矛盾、错误的数据及方法归属 | R07、R08。以实际知识、工程声明及合同核字段、承担方法、允许出口和验收。 |
| R7 有效读稿与重复往返 | R05、R06、R11。按材料键及对应修改区分纠错、漏改、重读与补交。 |
| R8、R9 越权、绕行与观测遗漏 | R03、R09、R12。将模型行为、宿主扩权、装置漏记及原生失败分别归因。 |

## 证据和收口

采用 [TEST §6](../../../test/TEST.md#6-评价) 和[金样审定条件](../../../test/golden/README.md)。两例 2.0.5 初段均有隔离问题，update 未测，旧建议分没有成为 2.0.6 的通过证据。新候选应给出正常输入、真实生产消费与旧路径退出、合法相邻输入/失败，并交代未测范围；使用者确认评分与发布。任何改变业务运行行为的评价条件都须能回到有效需求。后续若目录组合、可信独审接收或业务系统接点未获得正式证据，相关项记未验证，其他能力可独立评审。
