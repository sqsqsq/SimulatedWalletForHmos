# R3 分发、接入与 SVG 综合验收

2026-10-07 版本重整。本分册只维护 2.1.0 的验证对象与成本；原 G1/G2/Q1 和需求执行性能迁入 [2.0.3 R4](../2.0.3/04-综合验证与成本观测/需求.md)。通用操作/评分按 [TEST](../../../test/TEST.md)，不建新评测平台。

## 1. 输入与证据

输入为实际 Framework/Extension 组合、R1 接入合同、R2 图形能力、2.0.3 审定的语义基线及当前 diff/运行结果。版本、来源、请求终点和实际工作区明确。维护金样、分析和答案不进入消费模型。

确定性检查证明目录、入口、引用、图片和失败副作用；独立语义检查证明当前内容/关系；渲染证明实际可读性；成本比较同输入、同终点、质量合格后的实际代价。字段、语法、字数或单次样例通过不能替代组合结果。

## 2. 本版场景

| 组 | 场景 | 预期 |
|---|---|---|
| A1 | 首次分别取得机制/Wiki adapters，无 Story 入口和 knowledge | 三目录各就其位，用一次 /extension materialize 接入，不复制 Demo 答案 |
| A2 | 日常只替换 xxx，保留目标知识/身份/适配事实 | 不覆盖保留内容，只处理真实增量，契约未变不重取 adapters |
| A3 | 无变化重跑 | 幂等，不重复生产知识、派审或要求用户管理完成游标 |
| A4 | 职责交接 | 原生入口实际消费接入要求；旧 adapt/跳板退出，有效知识方法仍可取得 |
| A5 | 发布与隔离装配 | 只从根 xxx 发布；复制 Demo 后只换模板机制，目标知识/替身来源各自正确；测试不写 Demo |
| A6 | 独立 adapters 与路径 | 显式工程根/真实契约有效，旧内嵌副本和固定上溯退出，不建复杂兼容矩阵 |
| V1 | 六类维护域指导与两 Case 候选对照 | 先修语义，分别核结构/渲染/内容/token/耗时/返修；不硬造业务覆盖全部图型 |
| V2 | 实际完整图形交付 | SVG/Mermaid/无图各按真实结果验；按 R2 §4 下载 story-package.zip，解压后的三件、图片/来源相对引用有效；至少一条实际 SVG 生产及更新链，未生成 SVG 不能算端到端通过 |
| V3 | 正式 Case 自然选型 | 仅给通用指导，不指定某章用 SVG；未选 SVG 记未覆盖，不自动判错误 |
| P1 | 安装升级和 SVG 日常成本 | 用户动作、有效处理时间、token、返修与维护代价均核；不只挑下降指标 |

G1/G2 金样修订/切换与 Q1 普通内容质量由 2.0.3 验证，本版复用审定结果；如本版改动造成退化，回实际责任修，不用已签金样豁免。旧有效恢复/脏文件/人工入口保护沿相关回归，不扩异常状态矩阵。

## 3. 成本与交互

接入、升级、知识适配、图形生成/登记/检查/预览/返修/打包分别记实际请求与终点。人工等待、外部故障、上下文缓存和重复调用按已有观测口径披露；缺数据保留未知，不凭墙钟猜模型净耗时，不按报告数推修复次数。

质量合格再比较：日常升级是否仅换机制后调用一次原生入口，不重复取得对接包；无变化知识是否增量复用；图形全过程是否更清楚而不增加日常总成本。维护对照不进入每次业务的双版试画。定向能力与正式自然选型分别报告，单张流程图成功不外推全部图型。

## 4. 退出与完成

交回按旧职责→新承担者→消费者→保持覆盖→退出证据。目录迁移须同步发布枚举、知识加载、对接调用、工程根、模板装配、计量根和维护文档；原位置退出后不留下第二份日常维护源。有效安装保护和知识方法不能随旧 Skill 一起误删。

上游接口实际交付、相应场景成立、旧消费者退出、质量保持且成本证据可信后，才能签对应结果。Framework 与 Extension 分别记新增/复用/迁移/删除，职责搬移不等于成本消失。本轮无新预算或实跑授权，内网、设备、Coding 和发布按实际证据单列；图形或安装未验不冒称整版完成。

## 5. 签收判定

最终使用 R2 §6 的条件，不将“未覆盖”解释为自动通过：V1 六类指导有各自证据；V2 至少一条指定 SVG 的完整生产/更新/下载链；V3 两 Case 自然选型合理；至少一个优先场景的可读性与总成本依据成立。正式 Case 都未选 SVG 时，只要 V2 已成立，可签支持能力而保留自然使用未覆盖。系统二进制附件能力缺失时 V2 的系统交付不能签，不用本地截图替代。

V2 还核同名资源路径、缺资源不交付、更新后旧图不能配新稿、部分上传失败不记全成、重试保护人工修改。标准压缩/导出沿现有交付动作，不新建模板平台；确需公共新机制时后续计划另按维护契约裁定。
