# 2.1.0 评价标准变更准备

2026-10-25。需求依据：[Story 阅读与写作质量提升](2026-10-25-Story阅读与写作质量提升/00-需求.md)。用户决定在 2.0.x 发布后再决定何时实施；当前只登记标准影响和证据要求，不启用本版产品验收，也不覆盖 2.0.0 正在使用的标准。

## 1. 当前采用情况

成文核对时，全量标准工作件已由 2.0.0 任务更新为 [`extension-acceptance@19`](../../../test/regression/extension-acceptance.md)，目标仍是 2.0.0；此前 @18 对象保留在提交 `ddb9b222`。方法按 [TEST §6.5](../../../test/TEST.md#65-维护标准与评审)。本版尚未固定实施基线和专用标准修订，不将该在途工作件自动绑定为未来 2.1.0 验收基线。这里记录增量安排，标准正文仍只在 `test/regression/extension-acceptance.md` 维护。

## 2. 需求与标准的初步映射

| 本版目标 | 现行关联条目 | 本版需要核清的效果与判法 |
|---|---|---|
| R1 自然写作、R2 标题 | B1、B8 | 标题与正文的实际定位和理解作用；不能以禁词、标题句式或字段存在代判 |
| R3 长文组织、R5 全文与章节 | B1、B2、B6、B7、B8 | 首读路线、局部深入、查阅、章节独有用途、必要重现及无增益重复；不设篇幅门槛 |
| R4 图文配合 | B2、B3 | 所选形式能解释关系，图表文字互补；正式图与 SVG 增强分别判断，零 SVG 合法 |
| R6 归因与正常生成 | G3、G4、G5 | 实际送达、执行、产物和独审对应；不凭静态提示或人工修稿签效果，不预设新增评测机制 |
| R7 金样与效果目标 | G4、B1、B8 | 区分生成差距和目标改善，核输入及模拟前提；正本实质变化另审定，不注入被测模型 |
| AC8 能力保持 | B6、C 组、E 组、F 组及实际受影响项 | 保持局部落盘、追溯、人工区、归档及更新；依据真实改动扩核，不用无关全绿代签 |

此表只用于定位，不是新增计分分母，也不把父条目平均值作为目标达成。具体条件与验收见需求正文，正式标准修订时再核条目去重及保持集合。

## 3. 启动时的标准就绪条件

1. 取得实际发布的 2.0.x 标准和源码身份，核本版目标、已解决部分、仍有效的保持集合及原证据适用性。
2. 将有效增量合入唯一标准正文，保留能力 ID 并按实际变化修订条目；明确各版本适用范围，不改签历史报告或并行版本。
3. 核正常与必要反例能否区分正确、错误和合法表达差异；脚本只证明确定职责，阅读和语义用独立判断，真实效果从正常入口取证。
4. 固定本版采用修订、全部目标与保持集合及所需证据，完成必要复核后再进入产品实现。具体运行范围、预算与时机由届时 Plan 和授权确定。

当前状态：Spec 及映射已形成，未更新全量标准正文、未取得独立复核或本版运行证据，不具备实施开工或版本验收结论。
