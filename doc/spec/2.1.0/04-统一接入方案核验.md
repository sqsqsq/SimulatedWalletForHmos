对本轮有效总览、审查、R2/R3/R4 和本交回，连同只读的 R1 进行链接/章节、表格、文本空白和 Mermaid 静态结构检查。检查 SVG 六类与性能七项是否俱全，核 F1/F2 的输入、责任、完成条件和依赖是否明确；不新增文档检查平台。

保护比较覆盖：1.9.9 两份导航、历史参考全部内容、R1 两份文件、迁移清单、两个已完成记录、2.0 spec/plan、正式金样及其输入夹具、Framework 已跟踪发布件。并行任务可能改变其自己的代码，以实际写入范围和受保护内容摘要核本任务边界，不以整个工作区无 diff 作证明。

本轮开始 HEAD 为 c8414a7c，2.0 步骤 3 评审要求返修；核验时另一组已提交 f0046c6b 和 066d03aa。其 plan 目录新增“步骤3-返修交回”并更新执行者交接，目录由 33 份变为 34 份；已用提交间 diff 确认这两项变化，不声称整个 2.0 plan 目录前后相等。本轮没有暂停、提交或回退另一组工作，没有修改其文件或评定返修结果。写入仅限获准 2.1.0 spec，未改任何产品、Framework、测试、正式金样或原始探索。

13,450 及 1,300/650 保留为旧方案参考/估算，不作为本次新基线或额度。Framework 与 Extension 的真实实施成本需分别核算，本轮产品实际新增和删除均为 0。
