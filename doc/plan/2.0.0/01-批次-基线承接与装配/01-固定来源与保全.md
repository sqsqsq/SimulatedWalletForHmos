# 01 固定来源、保全与资料接续

输入：[参考01](../参考/01-成果保全与基线切换.md)、当前Spec、O/P/B/N、已有保全/评审原件。目标是“拿得准、找得到、恢复得回”，不替换产品。

动作：核工作区并保护doc/project及其他在途修改；冻结完整B产品/测试/资料、T相对O的后来资料和指定Git外运行证据；用原始blob与摘要保全并作代表性恢复。按参考01整理旧版本归档和活跃引用，项目级指南逐项给采用/合并/仅历史及目标；本批可落地不依赖产品变化的导航/维护规则，描述2.0行为的正文随相应实施同步，不提前写成已发布。

保持：旧2.x、原1.10.0评价建设、原评分/标准与新预算授权不被改签；源3.0和当前demo分别保身份。退出：当前入口中的失效版本指令，历史原件保留。

验收：来源清单与固定SHA对应，原件摘要及恢复成功、当前引用可读；未保全的具体原件列影响，不用摘要重造。验证只做枚举/摘要/必要恢复，不跑产品或模型CLI。

交回并提交本步维护资料；extensions G0/X0。无需等单步评审，前提成立进02；来源或所有权冲突只暂停相关项。
