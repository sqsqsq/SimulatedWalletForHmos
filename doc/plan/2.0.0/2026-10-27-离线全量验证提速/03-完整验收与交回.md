已有定向验证复用同对象证据；无变化不再跑旧慢基线。不启动“24 worker只收集”证明导入已无副作用，静态调用链和有限必要fixture检查即可。任何已知保留的不可重叠链单独超出窗口，先报告具体责任，不再用全量确认已知超限。

## 2. 最小验证分工

| 改动 | 恢复测试后所需证据 |
|---|---|
| 显式安装基底/共享 | 一次真实生产，两个独立消费者私有写入互不影响、入口/配置/字节正确；不启动全套worker |
| Git batch | 固定blob原始字节及独立补丁期望，真实缺失和读取失败分开；不新增Git模拟平台 |
| 最小输入与真实函数矩阵 | 现有正反预期逐项保留；实际遗漏必审/坏格式被具体拒收；不是只看退出码 |
| 生产者链保留 | 对应链真实写出状态，再被实际消费者使用；固定样本不代签该链 |
| 缓存/注入退出 | 全部入口和消费者一致退场；必要原生调用保持真语义，不为了删文件去构造新替身 |
| 装配默认恢复/调度 | 原生UPDATE实际默认环境、首次和第二次身份/证据分别保存；每项恰好执行一次 |

这些核查并入必要正确性验证，不额外逐族跑性能实验。少见异常不加矩阵，已证正常路径/历史缺陷/原件保护不删。

## 3. 一次固定候选完整验收

本轮最终命令仍为 `python test/scripts/verify.py handback --assembly`。入口至所有消费者退出、证据保存和清理的总墙时≤180秒，且功能全部通过，才达标。失败提前退出即使44秒也不算。

计时包含pytest启动/收集、首次真实装配、全部L1/L2/failure/runtime/编译语法，以及本次触发的第二次独立装配；不把它或新必要准备移到外部后扣时。不要求清空无关全局历史缓存，需新建的真实状态使用本候选合法输入/自然新键或私有空根，不预热隐藏成本。明确样本是输入不是执行缓存。

同时保留总时间、分通道/装配/收尾、源码差异、实际环境及固定输入、原始日志和必要未覆盖。跳过逐项记录真实原因；功能结果与性能结果分开，程序exit0不代替时间目标。

若超限，只按这次关键路径确认剩余成本；不调worker网格、不无限跑到绿、不因预算数字目标就删保护。如需改变必要覆盖、两次装配或产品职责，交设计者和用户，不自行改目标。
