# S2：新版Framework核实与适配定案

2026-10-18已取得并核实origin/main `2c83c182`的Framework 3.1.0发布树（source_commit `8deb32d0`）。[10新版核对](10-Framework-main新版核对与方案调整.md)维护精确身份、实际接口、F1–F8当前状态和本轮调整依据。1.9.9发布核实与[成果保全准备](01-成果保全与基线切换.md)仍可独立推进，不要求先替换源码。产品实施定案须两份发布身份、完整保全覆盖及必要依赖齐备。

## 1. 收件与正式接入

收件核对已完成：main发布树位于根framework，RELEASE-MANIFEST内1241文件缺失0/摘要不一致0；原始字节副本及MIGRATION已读取，详见10§1。当前story的demo/framework仍旧构建。后续正式接入只取固定main的framework子树，按同一身份制备发布包；不能merge整个main或覆盖根配置、AGENTS和归档资料。版本仍3.1.0，以source_commit区分。

正式替换demo/framework时按根AGENTS §6逐项执行：demo先干净，核迁移diff，重加两处本地定制，framework-init UPDATE，保护已装Story入口，根verifier同步，执行原生harness及相关离线验证，登记EVOLUTION。若新版改变这些接口，先形成具名接入差异裁定再执行，不能旧模板整文件覆盖新模板。

接入Framework与正式发布Story是两件事：允许按§6更新demo Framework，不提前把开发源安装到demo/doc/extensions。需要测试时用一次性template；恢复的1.9.9与新Framework并不自动兼容。Framework自身问题回上游，当前不代用户发送外部消息。

## 3. 正常、变化与失败推演

设计者沿两条正常入口推演：系统单取材至送审再update；本地单至蓝图、合法CU准备及Spec/Plan。另核直接Framework入口能否得到需要的Extension知识；没有业务编号或需求系统时不强迫制造系统单状态。多CU时共同设计不重复作、责任不漏传，无关联须有实际依据。

再核同名材料换版/撤回、未决影响准入、已有CU修订复用、正文表达修改、人工意见未接受、归档授权范围、报告无效后被原位编辑、视觉工具不可用、有效warn和重复调用。每条明确输入、权威决定、写入、下游消费、失败返回和恢复入口；推演不冒充行为证据。

合并选择引用[讨论](../../spec/2.0.0/01-蓝图与Story职责讨论.md)及10§4的实际承接边界。先采用原生@12作为需求级设计评审载体，Extension保留材料/人签、Review、归档/读回/恢复、update、资源与usage职责。独立Story全文是否还有必要由剩余读者价值和成本定案，不预定十章或立即删成文链；关键合并选择由用户确认。不会由同一方案同时维持两套设计权威或两套原生Markdown renderer。

## 4. S3开工前的交付

形成一套可直接实施的当前方案：逐能力新旧责任与唯一真源；Framework正式接口、版本和必读材料；extensions、test、配置与文档逐文件动作；删除、保留和保护清单；错误与恢复；定向/组合验收及预期；各实现步骤预计绝对G、X、净增、峰值和最终量。以[04](04-旧成果与能力承接清单.md)标记每项旧成果复用方式和证据边界。

逐文件动作必须覆盖[S1§2的完整同步范围](01-成果保全与基线切换.md#2-锁定真正的199发布源)：来源线更新的测试及相关资料与交付主体使用同一发布身份，给出实际目标、冲突处置和引用闭合结果；不能把文档增量统称“以后发布时再补”。

逐项补全S1中“已保全、复用去向待新版”的最终承担者和处置；1.9.9发布后变化补到能力/测试对应中。未发布承诺及既有缺陷明确留原版、经用户定范围迁入或后续处理，不依靠更新版本号关闭。首包同时确定源码切换、版本升为2.0.0、最小适配、安装/物化及相应测试；其后各包仍需可独立检查，不先交无法装配的纯恢复版本。

Framework未交付必要接口时只阻受影响动作，保留准确复现与所需交付，不在Extension实现通用框架旁路。不能将未定关键设计留给实施者猜。新增通用框架或生成器先按用户级约定说明必要性、成本及简单替代并取得确认。

S2通过条件是实施者仅凭本版当前方案及列明合同即可实施，且关键架构、预算及需用户取舍的决定已确认。当前已完成新版身份及主要接口核对；剩余为B发布差额、26项实际落点、人读/资源/Review/usage接口、F2/F4/F5覆盖与复验、逐文件首包和预算。尚未达到S3产品开工状态，但可以继续这些定向设计，不再等待Framework文件送达。
