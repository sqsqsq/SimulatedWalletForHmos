责任在当前使用说明。实施者在 README 入口和安装来源段明确：正文业务用法仍说明已发布 Story 1.9.8；本开发分支 demo 是 3.1 框架接入基线，组合尚未完成适配/真实验证；需要已发布 1.x 组合时使用 story-1.0 的 demo。不要把未经验证的蓝图行为写进当前使用方法，也不要只把依赖数字改成 3.1 就称支持完成。

完成条件：读者在试用或 adapt 前能分辨发布线与开发基线；README 与实际 demo 状态一致。只改说明，不运行对外 adapt、不改变包内容。该修正随能力核对交回一并复核，正式试用/发布之前必须完成。
