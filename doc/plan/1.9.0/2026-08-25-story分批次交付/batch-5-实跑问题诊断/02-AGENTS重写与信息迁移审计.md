## 3. TEST.md 去重结果

旧 AGENTS 中的测试命令没有整体复制进 TEST：

- 执行者隔离、维护者代理需求方、正式 Case 授权、原生 gate、阶段凭证、回灌三方检查、离线验证原本已存在，保持一份；
- `TEST.md §7.2` 在原负面扫描章节内统一使用 `rg`，补入唯一缺少的「交付面维护历史」扫描，不新增平行章节；
- Case 业务词继续由 M02 动态派生，不在命令里维护固定业务词；
- `TEST.md §7.3` 继续作为维护不变量到 failure-mode 台账的唯一映射；
- 多会话状态归属的一手证据并入现有 `TEST.md §5`，没有新增另一套状态规则。

## 4. 重写结果

- 顶层角色只有维护者、执行者两种；
- AGENTS 仍覆盖整个 Extension，不是 story skill 的局部规则；
- 测试执行细节只指向 TEST；
- 历史与当前实现快照不再占用常驻上下文；
- 旧文件中仍有效的维护约束均有当前权威落点；
- 退役机制与历史否决方案被保留为证据，但不再伪装成永久运行规则。
