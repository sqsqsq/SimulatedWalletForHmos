# N1 评测通路根因与修复（已实施）

## 现象

AR90004（`cross-component-rich`）连跑三次，全部 `finished` 但**产物一个不产**：
模型走完 S1–S3、给出完整初析摘要与推荐项，然后输出三选一菜单等人回话——
单轮 CLI 没有第二个人，会话就此结束，S4 与 `/spec` 从未执行。

## 根因

`opencode run [message..]` 的 positional 是 **yargs array**，会贪婪吸收后续非选项参数。
配置曾写成 `run {prompt} --dir … --format json`：**单行 prompt 相安无事**，
而真实用例 prompt 是多行长文本，于是 `--format json` 被吸进 message 数组，**从未生效**。

一处失效，三个症状：

| 症状 | 后果 |
|---|---|
| 输出退回 TUI 文本（带 ANSI），无 JSON 事件 | `model` 流全空——TEST.md 明写「**必须读 model 流**」，通道等于没有 |
| adapter 拿不到 `sessionID` | `run.json` 的 `session_id` 为空 |
| 无 `session_id` → 无法 `resume` | 驱动器**答不了** S3 菜单，单轮即终 |

实测复现：同一条命令，prompt 换成多行立刻退回 TUI（`> build · deepseek-v4-flash-0731`）。

## 定界（三次误判的记录）

| 层 | 判定 |
|---|---|
| **测试驱动器** | **根因**（见上） |
| story skill | **无缺陷**。S3 停等在有人应答时完全正确——SKILL.md 已写明理由：「完整提取件 `AR/design.md` 此时尚未生成，范围没定先生成的草稿必然报废」 |
| 被测模型 | 无过错。三次都正确判出推荐项，只是没有人回话 |

**两次错误修法（记下来免得再走）**：

1. **「在 SKILL.md 里列关卡授权语汇」**——复制 framework `BATCH_PHRASES` 已踩的坑：
   它列 5 条正则，用例恰好是第 6 种说法；我列 5 个词，第 7 种照样落空；
2. **「关卡默认改成决策并继续」**——为迁就单轮驱动器去推翻多轮交互的正确设计，
   本末倒置：真实用户会因此失去在 `design.md` 生成前纠正范围的机会。

**三次改用例措辞也全部失败**，这才是决定性证据：

| 措辞 | `resolveTransitionPolicy` 实测 | 模型行为 |
|---|---|---|
| 原措辞「无需逐一找我确认」 | `manual` | 停等 |
| 「全自动模式跑完」 | `goal_mode`（正则命中） | 停等——模型读了 §8.1「非对话内自驱动」判定要 runner，**它是对的** |
| 「做到 design 为止」 | `batch_authorized` | **仍然停等** |

第三次说明问题不在措辞。真正的变量是**有没有人能回答**，而 skill 判不出自己跑在哪种宿主里
——所以正解是让驱动器回答，不是逼 skill 别问。

## 修复

| 文件 | 改动 |
|---|---|
| `tools/cli/config/clis.json` | `{prompt}` 移到所有选项之后（opencode 的 readonly/build × args/resume_args 共 4 处） |
| `test/story/scripts/run_case.py` | 加续话循环：CLI 结束但**产物未齐**则 `resume` 续一轮，回话「按你推荐的选项继续」；上限 `MAX_TURNS=6` |
| `tools/cli/tests/test_registry.py` | 断言位置参数排末尾——**只约束 opencode**：这条从它的 yargs 实证来，claude 的 `-p`、codex 的 exec 另有形态，套上去就是过度泛化 |

两个判据都刻意不看文本：

- 续话与否看**产物是否齐备**（`spec.md` + `story.md` + `review.md`），不看菜单格式；
- 回话不指定编号，让模型按**它自己刚给出的推荐**走——菜单形态变了也不受影响。

## 验证

- `raw.jsonl` 31 行**全是 JSON 事件**（修复前 73 行零 JSON）；`session_id` 拿到；
- `model` 流可读（24 事件起，能看到「S1 完成」「inbox/ 只有 README.md」这类实时发言）；
- AR90004 跑通：2 轮 / 39 分钟，`turns=2`（1 次续话），
  三门禁 post_check / merge-story / story-build **全 pass**，`mechanical_verdict=pass`；
- 产物：`AR/design.md` 1466→9583、`spec.md` 25746、`story.md` 27453、`review.md` 8933、14 章节件；
- `tools/cli` 16 项测试与 story 域全量测试绿。

## 顺带确认

**AR90006（docx-supplement）现在也可自动测**，三个原先要人工的原因全部解除：
docx 由 `seed_case_workspace()` 在复位后自动铺入 `inbox/`；关卡由续话自动应答；
