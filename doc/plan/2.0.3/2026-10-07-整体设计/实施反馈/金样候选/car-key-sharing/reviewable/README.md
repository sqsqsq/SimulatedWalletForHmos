## 2. 语义差异（相对底稿）

| 项 | 底稿 | 候选 | 依据 |
|---|---|---|---|
| G06 入口宿主 | 写「分享能力加在钱包端既有的车钥匙卡上」；蓝图入口节点的现状写「车钥匙卡片无可点分享入口」 | 写明本工程没有车钥匙卡片，入口挂在哪里、接受后的钥匙由谁在卡包展示，登记为 D5（与工程现状矛盾的承诺）；蓝图新增待定决定 `share-entry-host` 和阻断缺口；风险表、流程、功能说明、验收、交付各处同步 | 蓝图自己的工程事实（车钥匙只是添加卡片页的不可点分类）；demo `CardRepository`、`CardPackPage` |
| G05 模拟承载 | D3 仍待评审，正文却写「端侧行为与验收不依赖服务端实现，接口就绪后替换为真实调用」 | 正文只写承载方式待评审；写明本地模拟验证通过不等于与车云联调通过；D3 方案 1 补上两种结论分开验收 | 决定登记 D3 的状态 |
| G04 对方身份 | 隐私的真源写「钱包端采集处脱敏」；SEC-01 要求在采集处脱敏 | 展示处打码，列表用车云返回的打码标识；查权限与创建分享时传可识别的对方账号标识；草稿保存它供续办并按规则清除；附录接口表写明不是展示用的打码账号 | SR §4.1b、§4.2、§5；SEC-01 新原文「展示用的不可逆掩码只用于展示」 |
