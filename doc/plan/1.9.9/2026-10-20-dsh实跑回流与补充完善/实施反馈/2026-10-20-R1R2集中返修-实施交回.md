## A. R1：测量按调用计

**唯一处理位置**：`test/scripts/measure_run.py` 新增本文件内的纯函数 `tool_call_view`，把公共 tool 事件归并成调用，`measure`、`segment_metrics`、`render` 共用它。它不写文件，也不新增状态。

| 04 配对规则 | 实现 |
|---|---|
| 同 run_id + tool_call_id 的开始与终态 | 一次调用：名称、入参取开始，输出、终态取结果，两头的事件位置都留着 |
| 并发交错 | 按键配，不看相邻行或工具名 |
| 不同 run 复用编号 | 键里有 run_id，各算各的 |
| 既有宿主的单条完整事件 | 带名字的终态事件自身就是一次调用（历史无编号记录同样处理，不和别的无编号事件猜配） |
| 只有开始 | 计用了什么、读了什么；门禁结论不推，列 `no_result` |
| 只有结果且没有名字 | 不造空名调用，列 `result_without_call` |
| 同键重复的相同事件 | 不重复计；同键互相矛盾的终态列 `conflicting_events`，该调用不出门禁结论 |
| 跨检查点 | 先在整份输入里归并，再按开始所在段归属，列 `crosses_checkpoint`，不拆成两次 |

**指标怎么消费**：
- `tool_calls` / `tools` 按调用计数。
- 读取判定只看开始的入参。shell 集合按 04 取 bash / pwsh / shell / shell_command，读取动词沿用原来的命令分段与 Get-Content / Select-String 识别。
- harness 与 Story 登记都在 shell 集合里按原有命令判据识别。
- `gate_rounds_with_fail` 与 `repeated_check_fails` 只取 harness 调用的结果。读一份旧报告不再算一轮门禁；旧口径是任何工具输出里有 FAIL 行都算。
- 首次门禁、登记与返工只看有结果的调用，按结果到达先后排。首次记录新增 `status`。命令报错（error / failed / cancelled）也算没过，不因输出里没有 FAIL 行就当通过。
- verifier 只认专用 `verifier` 工具与 `subagent_type=verifier` 的 task。其它委派（task、subagent、subagent_fork）记进每段的 `delegations_unresolved`。
- `*_gap_sec` 仍是事件间隔估计，间隔按所属调用的用途归属。
- `incomplete_tool_events` 非空时，文本报告首行写「统计不完整，仅为已观察到的次数」，并按原因列出条数。

**旧解释退出**：
- 删除逐条 tool 事件累加，以及「事件流里没有工具开始事件」的全局说明（文件头与 measure 内注释）。
- 删除只认 `name == "bash"` 的 shell 判定和「`task` 即 verifier」。
- `observe.py` 的工具摘要把 pwsh 并入 shell 一类，显示命令本身而不是整个入参字典；配对与计量没有复制过去。

**验证**（`test_run_measurement.py::ToolCallsArePairedFromPublicEvents`，9 条）：事件都由当前中央 adapter（dsh、codex）从宿主原始事件投影生成，再交给 `measure`，不只测内部 helper。

| 用例 | 断言 |
|---|---|
| 04 中性探针三次调用，加一次普通 subagent 源码研究 | 8 条事件计 4 次调用，没有空名工具。规则读取 1、checker 读取 1、harness 1。首次门禁含 sample_rule 失败（fail_count 1）。verifier 1，subagent 记进 `delegations_unresolved` 1，不算 verifier |
| 两次 harness 交错输出 | 2 次调用、1 轮失败；首次门禁是先到的那个结果 |
| 两个 run 复用 callId | 2 次调用，返工从 run-a 失败到 run-b 通过 |
| 错误结果 | 首次门禁 `status: error`，到下一次全绿计返工 |
| 失败报告再被读一次 | 仍是 1 轮 |
| 只有开始、只有结果 | harness 计 1 次但没有首次门禁结论；孤立结果不造调用；两条都列进诊断，render 出现「统计不完整」 |
| 同一结果重复、两个结果矛盾 | 重复的计 1 次；矛盾的列 `conflicting_events`，不出门禁结论 |
| codex 的 item.started 与 item.completed | 归成 1 次调用（已有宿主的正例） |
| 跨检查点的调用 | 只在开始的那段出门禁结论，列 `crosses_checkpoint` |
