# A03 共享来源导入、版本与所有读者

## 1. 输入与结果

依A02组合、主Spec R1/R5/R9及参考01§2。输入是系统AR/RR/SR关系与原件、本地inbox原件、原图、会议和有效人答。结果是一次取得/导入建立可追原件版本，Story/独审/update/后续来源描述都读同一库存，不再依赖根级固定材料路径。

## 2. 正常生产顺序

1. 需求初始化创建sources导航/收件区和必要AR流程位置。系统初次取得和update统一使用现有fetch取得职责并传sources/inbox批次路径，按参考01系统取得接点补真实关联与逐件回执；旧adapter init固定写RR/SR/AR路径调用退出。本地流程零远端；外部对接只负责取材，机制将其导入来源容器，不把测试系统实现写进通用机制。
2. importer按原归类能力解析docx/markdown/图片/会议，保原文件字节、转换正文、图与说明的关系。材料版本名可读，原文件名（即使spec.md等）原样在材料版本内部，避免原生Feature标志层混淆。
3. registry schema2→3按参考01存source_id、origin、取得版本及full SHA256、转换/图片关系。暂存校验后原子写材料版本与索引；同来源同内容重导入复用，字节或转换变化产生新版本，失败保旧版本/索引且列实际已写副作用。
4. 人答从真实已生效流程记录导出为来源版本，不再要求作者列人答ID；会议版本、有效/被替代答复按原身份保。索引区分最新取得和实际采用，未采用材料仍可查。
5. sources/README由索引派生导航，Story材料/来源/贡献显示从索引取信息；来源路径不等于采纳决定。现有图说明与unused/used判断转存到材料索引关联，避免新旧caption文件两边记账。

## 3. 文件动作与同一步切换

同步本仓`adapters/fetch.js`、`story.js`、`dirs.js`和取得消费者/测试替身，退出无调用的fetchOne固定目录初次取得；目标对接的能力缺口按所有权显式处理，不增加旧目录fallback。修改`core/materials/importer.py`的UX_DOC_TARGET/UX_IMAGE_DIR、inbox/backup落点与写入责任，`registry.py`的SOURCE_DIRS/CAPTIONS/ORIGIN及扫描/摘要，`meeting.py`版本读取，`import_sources.py`命令输出和参数说明。通用入口不硬编码案例名或用户路径。`story-chapters.json`的sources/update_files保护布局同步，源类型RR/SR/AR等概念保留，物理路径由来源索引解析。

同时修改所有直接读者：`core/story/sources.mjs`、`story-inputs.mjs`、`review-object.mjs`、`appendix-readers.mjs`、`design-source.mjs`、`flow/inputs.py`/routing材料盘点、update扫描/ownership、图/材料登记读取、需求init及本地/系统取材桥。定位来源按记录而非扫描同名目录；原图不能因路径变动丢原件关系。知识任务的来源入口也从同一索引取，A04再退旧交接，不由B/C补救材料读者断链。

旧frozen生产者在本步仍需能消费新来源索引作为已有交接的输入，**仅改其上游读取接口，不增加兼容分支或新快照功能**；A04整体退该交接责任。源码提交保当前链可验证，不让新材料位置与旧读者并存失联。旧任务schema明确拒绝，不回退读取旧目录。

相应`rules/inbox_import.md`、`init_analysis.md`、`phases/meeting-read.md`、`story-write.md`、SKILL目录说明及fixture同步。旧root UX、assets、RR/SR路径仅保旧版本历史，不继续作为新任务fallback。

## 4. 保持、失败与验证

保系统关联关系、本地零远端、同名/多版本、图片原字节/说明、会议原话、人答有效性、未采用材料可查。材料身份/转换发生冲突报具体源，读取失败不报空集；更新不能覆盖旧被引用版本。无需新增source注册服务/锁平台/任意格式兼容器。

定向用现有material/meeting/requirement_source回归和必要真实导入→registry→Story输入L2链。至少核：同原件重复无新版本；同名改字节增版；多个来源同字节仍保来源关系；原件转换图引用完整；用户原文件名为spec.md仍能在来源容器中保存而非施工单元；有效人答沿用、被替代人答留历史；图仍能被实际读者找到；索引坏/原件缺失保错误，不伪报充分。

局部命名/摘要/引用矩阵用L1，不能每个都重做安装和蓝图质询。材料内容语义、图面与会议理解由后续独审/正常Case判断，不以索引字段齐签通过。

## 5. 完成与预算

新任务的来源生产和全部直接读者同根成立，原目录活动引用退出，原件/人答/版本保持有证据；交回路径/身份前后对照、实际消费者、测试迁移、未实跑与预算并提交，连续A04。拟议G720/X900；移动和改路径本身不记X，实际退出的重复路径/图别名/扫描职责另核。
