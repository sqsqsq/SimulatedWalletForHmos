# S20 隔离证据与同轮派审归属

承接[01 批三评 R3/R4](评审意见/2026-11-24-215500-01批S16第三次独立复评.md)。第三轮返修，产品 G0/X0。沿既有测试域的度量器与观察摘要修正两项决策。

1. 用实际命令参数和工具结果区分内容输入、路径输入、读取失败、成功取到外部数据。能明确只是对字符串过滤时按内容处理；语法或结果不足以实证时列待核。保住真实管道文件输入、历史实际越界。避免维护一张 PowerShell 缩写黑名单。让执行者从真实 shell 对照完整写法、等义缩写、真实文件输入，再从公开 measure 命令读到最终停评状态。
2. 首次和再次派发都从实际工具调用的开始计算；工具返回较晚时保住已在本轮执行的合法 child 写。只将能唯一归属本轮且在本轮有效时间内有成功依据的写入计入报告。时间不全、同键续派重叠或成功回执跨轮，保留已知派审与收尾，实际报告/完整回复按可证事实记。用首次派发前写、缺调用时间、跨轮返回、正常先创建 child 后工具返回四组输入同时核报告和摘要，回放历史两案，给出剩余待核项。
