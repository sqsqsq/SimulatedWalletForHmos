# S02 隔离边界与真实审阅计数

[本批安排](00-批次方案.md) · [总方案三表](../00-实施方案.md) · [计量真源](../01-计量基线与投入.md)

**必读输入与前置**　测试装置。对应 R12、AC08/11/14/15。以 20261123 两例的 events、native-sessions、报告原件、宿主答复及复评时间线作固定对照。 可与 S01 并行。

**责任、文件动作与退场**　在 test/scripts/measure_run.py、observe.py、run_multi_case.py 和 TEST §3/6 核对真实调用、完成回复、材料键、报告与登记时间。同一对象可有多次调用，分别列派发、报告、有效完成；缺关联留未知。保住原 estimate 指标与历史文件。按事件的 cwd 解析相对文件位置，结合返回物识别旁案；动态拼接或截断交宿主核对实际返回。避免把执行脚本当读取源码。

**已定设计与合法分流**　宿主在实际问到选择时读到：“本轮止于方案，只确认业务条件和验收；需要改共享代码时，记录方案和影响，保持原授权终点。”另一合法输入是已明确授权实现，此时按授权运行；Case 专属答复只在测试域。隔离触点保留原行与影响段，停止该段正式评价。

**验证入口与通过条件**　只读重放同一套档案：蓝图 4/6 次派发，Story 5/4 份不同对象报告；auto 动态读取 DSH store、car 相对路径列旁案能定位；仅出现路径文字且没有读取要区别。人工等待、工具/委派重叠、未知与零分列。对照 test_run_measurement.py 与实际观察记录，不能修改原事件得到预期。

**交回**　重放读数、逐次报告与事件索引、宿主答复分类。 本步预估 G0/X0，按 AGENTS §5 报实际新增/退出、旧职责接替及未取得的证据。交付物的结构、语义和真实运行分别下结论。

**A3　宿主答复归属（11-24 生效）**　防止测试宿主扩大授权的指令只写入 `test/TEST.md` 和 Plan-only Case 的 `interaction-script.yaml`，不投到消费者的产品提示词。观察器仍按本卡记录已经发生的行为。S08 的产品指令仅处理实际用户授权的施工终点。 [裁定与复验](../评审意见/2026-11-24-000641-开工疑问裁定.md)
