# S13 真实交付与版本评价

[本批安排](00-批次方案.md) · [总方案三表](../00-实施方案.md) · [计量真源](../01-计量基线与投入.md)

**必读输入与前置**　实跑宿主、内网维护方及最终用户。R01–R12，AC01–15。必读 TEST §0–4/6、正式候选、金样的有效前提。 S12 冻结、用户明确启动；内网真实环境另取签收。

**责任、文件动作与退场**　用户授权后，统一候选以 DSH + 百炼 deepseek-v4.1-flash-1017 运行 auto-topup 到真实送审、car-key-sharing 到获准 Plan，auto 原初段 checkpoint、promote 后在同一会话跑一次 update，car 不追加 update。起跑条件未满足不提前插模型轮次。保首稿、历轮固定件、实际收到的人答、独审原报告、终稿、外发回读、检查点和时间。

**已定设计与合法分流**　输入提示只述 Case 任务。宿主只答实际所问；越界解析到实际目标与返回，按 TEST 停该段正式评价。分别核 AR 成文/非 AR 免写离线对照、已定授权、获准 CU、阶段原件、实际改稿及交付；未发生结果记未覆盖。内网安装首装/升级由现场用真实发行与对接确认。

**验证入口与通过条件**　按当前采用标准核 58 项、三轴及对照条件，给建议分和限制，评分由用户确认。测试发现问题并修改交付物后，下轮获准 CLI 前重新更新 demo、验证入口并固定候选。发布批准后由最后通过的外网 extensions/ 提交发行，核对 demo、Case 与发行身份，更新 README 与版本说明。

**交回**　作为本批最后一步合并两例、update、内网及未知项，交独立整版效果评审；不因离线绿或一次投放收口。 本步预估 G0/X0，按 AGENTS §5 报实际新增/退出、旧职责接替及未取得的证据。交付物的结构、语义和真实运行分别下结论。

## 修订 4 的真实成品并读

在原定的两例及一次 update 中保留提纲、初审稿、修改、登记版本及最终送审/回流文件。与 1.9.9 同名实稿、2.0.5 初段及两组金样按相同业务责任比较：读者能否从目录定位主题、沿一个主要载体判断条件与去向，图前能否入题，图后是否只补影响判断的图外事项。标出具体稿件位置、改稿是否丢编号、例外是否保住；图表数与段长只作定位，继承输入差异和污染边界。本项不新增中间 CLI。

**S33 首装效果。** 在获准的同一最终真实验证窗口，独立使用知识为空的陌生目标，按 [S33](../04-批次-三方发行与就地适配/S33-无样例首装生成项目知识与受测版本发布.md) 核无成品样例条件下的首稿、源证、遗漏／误写、改稿和下游是否能据此作决定。已有 demo 不清空，两项 Story Case 及一次 update 仍按原输入运行。取不到真实首装证据，或目标可证的关键知识仍有影响决定的错漏时，不签无样例退场和发布；在相应作者／独审真源修正后用同一目标复验。
