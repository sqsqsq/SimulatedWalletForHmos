**责任、文件动作与退场**　使用既有 verify.py 的 cases/affected/assembly/handback 及规定组合；先核包、pin、实际物化与补丁、全部激活文件、DSH 配置和模型生效读数。复用上版外部模拟时限判断，保失败记录。测产品 usage/stats 与运行观察者分别取数；保留发布后正文/附件部分失败及远端人工冲突保护。两组金样模拟前提显式对照；测试答案不送模型。

**已定设计与合法分流**　汇总每项被替换的旧读面、旧消费者和专用测试的去向。用真实发布物在隔离工程执行安装，用户面对的入口可用；多个分支不同 tree 的通过不能拼成一次冻结。

**验证入口与通过条件**　固定候选标注提交与实际工作树、Framework 发布身份、完整输入 SHA、DSH profile 实际解析模型、宿主桥、58 项适用状态及全部未覆盖。依赖不足只签子项，S13 不起跑。

**交回**　离线组合、预算与退出裁定、候选冻结清单，交设计者独立判断。 本步预估 G0/X0，按 AGENTS §5 报实际新增/退出、旧职责接替及未取得的证据。交付物的结构、语义和真实运行分别下结论。
