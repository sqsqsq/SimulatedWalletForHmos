# S17 章层级与作者旧指令退场

承接[02 批首评 R1、R2](评审意见/2026-11-24-193624-02批S03至S05独立复评.md)。针对 S04 的实际入口，预估 G12/X16，批准沿同一包计量。

- 在已有结构检查区分“可计算的序号”和“无法计算因为缺少父级”。正常 H2→H3→H4 可定稿，出现 H2→H4 或更深层断层时，给出行号、章和缺的父级，在派审/登记/交付前停住。遵守围栏及已有人工区保护，不能凭脚本猜出作者的小节主题。公开入口复核原反例和合法多层小节。
- 令实际写作设计覆盖合同全部十个 ID，包括附录。已有的空提纲首次创建仍照原流程；已经填写却缺第十章时返回提纲问题，不能直接派写第一章。替换原先肯定缺附录豁免的专测，保住附录的投影责任与有效写法。
- 对齐 `story-write.md` 和实际草稿指引：不适用章保留章位，让读者读到该需求的简短依据；图后补充信息和它的图对应清楚即可，正常且有用的小标题可用。保留图前短导读、图中主关系、图外简洁列表及无需补充时自然收束。用“有依据的单句”和“只有空模板”的稿件、合法图注和逐箭头复述两组输入走读，不增加字数/图数门。
