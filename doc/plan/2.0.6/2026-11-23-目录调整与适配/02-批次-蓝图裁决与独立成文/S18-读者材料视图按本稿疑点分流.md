# S18 读者材料视图按本稿疑点分流

承接[02 批首评 R3](评审意见/2026-11-24-193624-02批S03至S05独立复评.md)，预估 G8/X12。沿原 S05 的对象绑定及双全文合同。

在 `reader-review-task.mjs` 附录材料段与 `sources.mjs` 共享来源视图分清共用事实和角色动作：读者应见已采用版本、追溯库存与固定位置；普通未采用的较新版仅在稿件主张有具体疑点时查。属于作者的“为什么没采用每个新版/每张图”留到设计责任方。有效原话、当轮改稿、确实被稿件使用的业务主张和必要的图文依据仍按原合同核。优先复用同一事实枚举，在实际角色入口编排其动作，避免复制整套材料事实或增加新审计表。

用同一 PRD 一份采用版、一份无矛盾的库存新版，读完整 prepare、dispatch 及嵌入规则：不得在附录或图片段重新要求逐一核弃用理由。再把正式稿写成库存里未获授权的结论，读者应有固定原件可查并指出错误与责任。换库存版本照样失效，缺固定件保原任务；不可用、已有 fail 和截断报告均保既有分流。S17/S18 同一提交对象提供真实输出、退出清单、累计预算与规定批末组合，不在本步重跑模型。
