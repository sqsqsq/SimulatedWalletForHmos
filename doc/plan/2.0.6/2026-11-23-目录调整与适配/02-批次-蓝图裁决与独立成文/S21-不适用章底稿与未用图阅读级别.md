# S21 不适用章底稿与未用图阅读级别

承接[02 批二评 R2/R3](评审意见/2026-11-24-215500-02批S17与S18第二次独立复评.md)。第二轮返修。两项合计预计 G8/X14（章稿 G5/X9、读者视图 G3/X5）。

- 作者：在现有章合同生成器、章提交校验和错误返回统一取本单实际依据。去掉可直接提交的预填空句、空输入时指示只写固定句的提示及其专用豁免。作者首次拿到的章稿须能引导写出不适用的具体依据，已有依据可直接用；通用空模板由现有结构识别，依据是否成立交现有独审。保合法简短单句、十个固定章位、正常子层级及免写场景。从真实 skeleton → chapter → prepare → 登记/交付读，提交空模板、实际理由、正常多级三组；在完整稿查可见理由。挂靠已有层级报错顺带标明章，不另加检查器。
- 读者：由既有对象表把阅读级别交到图片行与派审任务，采用且承担语义的图必须看，未用图固定身份并按疑点回查。保同字节别名、原 bytes 换版失效和未用图实质被正文引用时应核的分支；同一图片在多处出现时依真实用途。公开 prepare 比对 object/task/dispatch 的总则、行标和图像约定，换真实图字节再核旧报告失效。
