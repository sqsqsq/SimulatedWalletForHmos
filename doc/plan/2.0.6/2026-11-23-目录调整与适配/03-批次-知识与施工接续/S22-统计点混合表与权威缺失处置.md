# S22 统计点混合表与权威缺失处置

承接[03 批二评 R2/R3](评审意见/2026-11-24-215500-03批S19第二次独立复评.md)。第二轮返修。R1 作者已签收。预计 G11/X12（表及其消费 G5/X5、阶段准备 G6/X7；授权对照为测试域）。

1. 沿同段真实表头、数据行及职责列的同一解析结果给门与独审。合法说明表可保留；含实际点位和方法却不能分出两个独立职责列的记录应指出具体表与行。某张有效表不能遮住另一张待核的数据表。无法仅按结构确定含义时保留原表交现有独审，不计它作已覆盖的行。撤下按单字符穷举合并列名的逻辑。复验加入说明表、仅混合表、有效表旁追加混合记录、历史子节，核门与派审正文，不以换词表代替修正。
2. 冻前直入 Plan 时以当前正式 pin 的原生投影返回状态、产物与失败原因分流。权威有效但本地缺所需产物，走原生准备；权威 invalid，带原生原因和负责方停在准备/冻结前；确无义务、有合法产物、已冻结均沿原入口。退出扫描错误详情来决定可物化的分支，按 pin 的函数签名调用，保合法局部深化、原契约及请求。由真实预览走到原生准备或正确停点，用「权威可生成」「权威自身缺」「无需用例」成对复验，把最早原因和前后写面交回。
3. 离线对照仅改变同一请求授权。保存该请求、真实原生步骤的终点或停点、前后业务源码清单/摘要及差额。未执行编码应照实记录；未授权运行真实模型，不提前 S13。仅由 phase_chain 推出的零写入不作实测差异。

与 S20、S21 及已获准的 S10/S11 并行；最终布局由 S10 汇合。
