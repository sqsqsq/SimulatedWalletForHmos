# S07 统计点与真实恢复合同

[本批安排](00-批次方案.md) · [总方案三表](../00-实施方案.md) · [计量真源](../01-计量基线与投入.md)

**必读输入与前置**　结构识别和提示词。对应 R07–R08、AC09–10。读 stat-points.mjs、host-chapter.mjs、plan/post_check.mjs、pre_verifier.mjs、blueprint/author.md、知识协议。 S01 后，独立于 S06；共用作者页分段合并。

**责任、文件动作与退场**　复用章节归属及列下标，只解析本期职责段直接所属表；按主列名识别，保留附注、列交换和同点多结果，删除对整格附注中“示例/其它职责词”的黑名单。单格混合两职责不能算两列，结构歧义报位置和实际表头，只有真实缺数据才报缺行。方法须真实引用，数字、事件 ID 和渠道归目标知识。去掉交付知识协议中为躲维护用例而规定的题材/例子数。

**已定设计与合法分流**　写给蓝图作者：“结果未知时按已有端口说明确认责任、合法请求身份及可继续条件；没有确认能力，保留未知。”同时核质询输入。查询、回调与原请求幂等重送都只在合同成立时使用。不能把示例流程号或模拟账号显示串登记成项目事实。

**验证入口与通过条件**　复用生产 Plan 门和独审装配，三种方法列标题应都取到原行，换顺序、混合列、历史/当前共存、确实缺方法分别核。换一个业务及恢复合同，设计不会被强制查询；看真实验收对允许透传与禁止泄露给出互容边界。

**交回**　生产门、读者输入和有效蓝图/契约的正反例。 本步预估 G18/X24，按 AGENTS §5 报实际新增/退出、旧职责接替及未取得的证据。交付物的结构、语义和真实运行分别下结论。
