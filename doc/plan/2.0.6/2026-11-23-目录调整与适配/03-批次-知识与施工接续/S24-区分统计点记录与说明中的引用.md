# S24 区分统计点记录与说明中的引用

[03 批三评 R2](评审意见/2026-11-25-003500-03批S22第三次独立复评.md) 续办，R1、R3 已通过。前置于 S12，预计 G5/X6，原 03 批余额 G3、追加 G2。

在已有逐点表生产门和独审取材处共享当前设计点位与实际职责列。取得两个独立职责列的正式表照原规则判；明确将已知点位与方法合填的数据表保留行号、表头和原行，即使旁边已有一张有效表也要处理。非逐点说明表里的方法、文件名和带点文字只作说明；不足以由结构判定为实际点位记录时保留原表供既有独审判断，不能硬拦，也不计覆盖。撤掉「任一数据格有点号串就报结构歧义」的条件。复用现有原件和读者，不扩展连接符或文件名黑名单。

在同一合法 Plan 只换说明表内的文字（无引用／引用真实方法／引用文件），再切换为真实混合点位记录。通过生产 Plan 门与 pre_verifier 的任务核三种说明均可读、真混合可定位、历史行与点位覆盖不混入。保持缺真实方法的现有检查。执行者随 S10 的目录迁移合入最终唯一源；S23 与 S11 可并行。
