## 需求正文

我希望在钱包应用里加一个**卡中心**的改版：

1. 用户从首页底部 Tab 切换到**我的**页面后，能看到"卡中心"入口的快捷卡片，点进去跳转到**卡中心**页。
2. **卡中心**页要展示用户已添加的卡（模拟数据即可），卡片要能横向滑动预览，最多显示 8 张。
3. 卡中心页顶部有一个"添加卡片"按钮，点它跳转到**添卡入口**页，添卡入口页先展示支持的卡种清单（银行卡、交通卡、门禁卡三类）。
4. 如果当前没有登录的**账号**，卡中心页应该显示"请先登录"的占位，点击占位会触发登录。
5. 所有卡片的"删除"操作暂时不开放，点"删除"只弹 Toast "暂不支持"。
